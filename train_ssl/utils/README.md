# Utils 工具说明

## bbox_analyze.py

**设计目的**: 为 3D ResNet 训练前的数据预处理，确定合适的裁剪尺寸（bbox），避免信息损失。

### 功能一：分析 BBox 距离
**为什么需要**: 了解数据集中所有 mask 的实际尺寸分布，为后续裁剪尺寸选择提供依据。

### 功能二：计算百分位数
**为什么需要**: 通过 95/99 百分位数确定裁剪尺寸，确保大部分样本都能完整保留，同时控制输入尺寸。

### 功能三：统计 Crop 外体素
**为什么需要**: 验证选定裁剪尺寸的合理性，评估有多少 mask 信息会被裁剪掉，避免过度损失。
